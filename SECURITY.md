# Security policy

This repository is a list of links, not software, so the realistic risks are **malicious or compromised links** and **repositories that ask readers to run unsafe code**.

## Reporting

If a listed resource has been hijacked (domain taken over, repo turned malicious, tutorial now serving malware or phishing):

1. Use **Security → Report a vulnerability** on this repository (private), or
2. Open a public issue with the **Broken link** template if there is no immediate risk to readers.

Please include the entry, the URL and what you observed. A confirmed malicious link is removed immediately, before any replacement is found.

## Supported versions

Only the current `main` branch is maintained.
